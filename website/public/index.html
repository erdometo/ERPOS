Model Context Protocol (MCP) Integration

Connect OmniGate's autonomous kernel and SAG steering engine directly into your favorite agentic IDEs.

Claude Code Configuration claude.config.json / ~/.claude.json 
{
  "mcpServers": {
    "omnigate": {
      "command": "npx",
      "args": [
        "-y",
        "@omnigate/agent-link-mcp",
        "--db=./erp_database.db",
        "--mode=sag"
      ],
      "env": {
        "OMNIGATE_KERNEL_MODE": "autonomous_zero_ui",
        "SAG_STEERING_ENABLED": "true",
        "MAX_LATENCY_MS": "15"
      }
    }
  }
}
CLI Fast Add: claude mcp add omnigate npx -y @omnigate/agent-link-mcp --db=./erp_database.db

        "./node_modules/@omnigate/cursor-mcp/bin/server.js",
